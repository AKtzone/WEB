这是我的个人网站，使用 Astro 框架搭建，部署在 GitHub Pages 上。

## 功能特性

- ✅ **首页** - 个人简介 + 精选内容展示
- ✅ **博客系统** - Markdown 写作，自动生成列表和详情页
- ✅ **作品集** - 展示项目作品，支持链接跳转
- ✅ **关于我** - 个人介绍和联系方式
- ✅ **响应式设计** - 适配手机和电脑

## 技术栈

| 技术 | 用途 |
|------|------|
| Astro | 静态站点生成框架 |
| TypeScript | 类型安全 |
| GitHub Pages | 免费托管部署 |
| GitHub Actions | 自动化 CI/CD |
