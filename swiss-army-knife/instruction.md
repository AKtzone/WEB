# 综合瑞士军刀 · 开发指令

## 📋 项目概述
开发一个单 HTML 文件的综合工具页面（Swiss Army Knife），采用标签页切换设计，集成 6 个常用开发工具。**零依赖，纯原生 HTML + CSS + JS**，拖到浏览器就能用。

## 📁 文件结构
```
swiss-army-knife/
├── index.html          ← 唯一的文件，全部代码在此
└── instruction.md      ← 本文件（开发指令）
```

## 🎨 设计规范
- **主题**：深色模式（Dark Mode）
- **主色调**：背景 `#1a1b2e`，卡片 `#232540`，边框 `#2d2f54`
- **强调色**：`#7c5cfc`（紫色）用于按钮/选中态/标签高亮
- **字体**：系统字体栈（`-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif`）
- **圆角**：12px 卡片圆角，8px 按钮圆角
- **响应式**：适配 768px 以上屏幕，卡片网格布局

## 🔧 各工具功能定义

### 1️⃣ JSON 工具箱
| 功能 | 说明 |
|------|------|
| 格式化 | 美化 JSON（缩进 2 空格） |
| 压缩 | 移除空白，一行输出 |
| 校验 | 语法检查 + 错误行号定位 |
| 树形浏览 | 可折叠的 JSON 树（纯 CSS 实现） |
| 清空 | 一键清空输入框 |
| 复制 | 复制格式化后的结果 |

- 输入区域和输出区域并排（左输入右输出）
- 输出带语法高亮（用 `<span>` 着色：key=青色 `#7ec8e3`，string=绿色 `#98c379`，number=橙色 `#d19a66`，bool/null=紫色 `#c678dd`）

### 2️⃣ 正则测试器
| 功能 | 说明 |
|------|------|
| 输入正则 | 输入正则表达式（如 `\d+`） |
| 输入文本 | 要匹配的文本内容 |
| 实时高亮 | 匹配项以黄色背景高亮显示 |
| 分组提取 | 显示匹配组（capture groups）列表 |
| 修饰符 | 全局(g)/忽略大小写(i)/多行(m) 复选框 |
| 测试结果 | 显示匹配数量 + 位置 |

### 3️⃣ 时间戳工具
| 功能 | 说明 |
|------|------|
| 当前时间 | 一键获取当前 Unix 时间戳（秒+毫秒） |
| 时间戳→日期 | 输入秒/毫秒时间戳，转换为人可读日期 |
| 日期→时间戳 | 选择日期时间，转换为 Unix 时间戳 |
| 时区选择 | UTC / 本地时区切换 |
| ISO 格式 | 同时显示 ISO 8601 格式 |
| 格式模板 | 可选预设格式（YYYY-MM-DD、YYYY年MM月DD日等） |
| 一键复制 | 复制结果到剪贴板 |

### 4️⃣ 编解码器
| 功能 | 说明 |
|------|------|
| Base64 编码 | 文本 → Base64 |
| Base64 解码 | Base64 → 文本 |
| URL 编码 | 文本 → URL 编码 |
| URL 解码 | URL 编码 → 文本 |
| HTML 实体编码 | `< > & " '` → `&lt; &gt; &amp; &quot; &#39;` |
| HTML 实体解码 | 反向解码 |
| Unicode 转义 | `你好` → `\u4f60\u597d` |
| Unicode 反转义 | 反向转换 |

- 编码/解码结果框自动显示
- 每个功能下方直接展示结果，不跳转页面

### 5️⃣ 文本 Diff
| 功能 | 说明 |
|------|------|
| 左右对比 | 左右两栏输入框 |
| 行差异 | 新增行=绿色背景，删除行=红色背景，修改行=黄色背景 |
| 行号显示 | 两侧行号对齐 |
| 差异统计 | 显示：新增行数、删除行数、修改行数 |

- **Diff 算法不依赖第三方库**，用逐行字符对比的简单实现（LCS 算法简化版或逐行对比）

### 6️⃣ 颜色工具
| 功能 | 说明 |
|------|------|
| Hex→RGB | 输入 `#ff6600` → 输出 `rgb(255, 102, 0)` |
| RGB→Hex | 输入 `rgb(255,102,0)` → 输出 `#ff6600` |
| HSL 显示 | 同时显示 HSL 值 |
| 颜色预览 | 显示颜色方块预览 |
| 色值复制 | 一键复制任意色值 |

## ⚡ 交互要求
- 所有操作**即时响应**，不做异步请求（纯前端）
- 输入框实时触发转换/校验（keyup 事件或按钮点击）
- 按钮 hover 有微动效（`transform: translateY(-1px)` + 阴影过渡）
- 标签切换有平滑过渡动画（淡入 200ms）
- 复制按钮点击后显示 "✅ 已复制" 提示，2 秒后消失

## 📱 响应式
- ≥768px：标签横向排列
- <768px：标签改为横向可滑动（overflow-x: auto）
- 输入框在手机端自动占满宽度

## ❌ 不要做的
- 不要引入任何 CDN/外部资源（包括字体、图标库、CSS 框架）
- 不要使用 ES Module（`import/export`）—— 全部用 `<script>` 标签内联
- 不要使用 `localStorage` 或任何持久化存储
- 不要写多余文件，**只有一个 index.html**

## ✅ 开发完成后的验证
1. 用浏览器打开 index.html，确认所有标签页可切换
2. 每个工具手动测试一下功能是否正常
3. 确认深色主题渲染正确
4. 确认无任何控制台报错
